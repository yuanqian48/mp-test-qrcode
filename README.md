# 微信测试号工具集

本项目包含两个独立的小工具，均围绕**微信公众平台测试号**开发：

1. **易语言编写**的测试号管理软件（半成品，含源码）
2. **Golang编写**的简单示例，演示获取登录二维码及基础信息

│   ├── 推送模板示例/
│   └── readme.txt
├── wepush.go      (Golang示例代码)

## 第一部分：易语言 · 微信测试号管理工具

### 🔧 功能特点（已实现）
- ✅ 程序启动后加载登录页面，支持**微信扫码登录**测试号
- ✅ 登录后自动获取 `access_token`
- ✅ 调用**未公开接口**获取测试号粉丝列表（返回粉丝昵称、OpenID）
-  PS:没有测试扫描登录时获取的cookie有效时长，所以默认每次打开软件重新扫描登录
- ✅ 调用**未公开接口**实现模板消息的新增
- ✅ 调用公开接口获取已存在的模板列表
- ✅ 调用**未公开接口**实现模板删除   该接口未在代码中实现
-  **请求地址**：`https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo`  
-  **请求方法**：`POST`
-  **请求头**：携带cookie即可，可以参考易语言代码中获取openid部分
-  **参数**：`tmpl_id=模板id&random=随机数&action=deltmpl`
-  **成功结果**：`{"errcode":0,"errmsg":"ok"}`
-  **说明**：`random` 可为固定值（如 `0.5634696955228937`）或动态生成

## 第二部分：Golang · 获取测试号登录二维码示例

基于go语言简单实现的例子，演示如何通过微信公众平台测试号接口，**获取登录二维码**并在用户扫码登录后**获取 appid 等基础信息**。
-写的很简陋，思路都是野路子，勿喷🙏
### 🚀 快速开始

#### 环境要求
- Go 1.16+

#### 运行步骤
1. 克隆本仓库或单独下载wepush.go
2. 配置golang运行环境
3. 运行：
   ```bash
   go run wepush.go
   ```
4. 程序将输出登录二维码 URL，扫码后即可获取相关信息。

### 📌 说明
- 本示例仅展示核心流程，代码简洁，适合初学者理解微信测试号登录机制
- 实际使用时请根据微信官方文档完善错误处理和安全性措施
